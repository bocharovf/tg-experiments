# AGENTS.md — tg-experiments

Публичный репозиторий с кодом экспериментов ТГ-канала «Техновыживание». Идея: из поста человек переходит в репозиторий, чтобы **повторить** эксперимент; из репозитория — в канал, чтобы узнать **результат**.

## Структура
```
experiments/<slug>/
  README.md    что это, как запустить, сколько стоит
  *.py         код эксперимента
  scripts/     вспомогательные скрипты (графики, подготовка данных)
  data/        данные (если не генерируются на лету) — в git НЕ попадают
  results/     результаты прогонов — в git НЕ попадают
docker-compose.yml
```

## Требования к README эксперимента
1. Что это и какой пост в канале этому соответствует (ссылка `https://t.me/technosurvival/<id>`).
2. Что должно стоять на машине (зависимости).
3. Как запустить — **и локально, и через Docker** (предпочтительно именно Docker: минимум требований к инфраструктуре).
4. Сколько стоит прогон (в деньгах и токенах).
5. Как построить график/получить результат.

## Правила
- **Секреты не коммитить.** Ключи — только в `.env`, а в репозитории — `.env.example` с заглушками. Перед каждым коммитом проверять `git diff` на ключи и пароли (в истории проекта это уже случалось).
- `data/` и `results/` — в `.gitignore`.
- Один эксперимент = один каталог. Компактно, воспроизводимо, без «магии».
- После изменения — обновить список экспериментов в корневом `README.md`.
- Коммиты — по-английски, понятные (`add experiment: anonymization`).
