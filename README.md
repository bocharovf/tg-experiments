# tg-experiments

Код экспериментов из ТГ-канала [«Техновыживание»](https://t.me/technosurvival).

Хочешь **повторить** эксперимент? Клонируй и запускай по README в каталоге
конкретного эксперимента.

Хочешь узнать, **что из этого вышло**? Результаты, выводы и цифры — в канале.

## Эксперименты

- [needle-in-haystack](experiments/needle-in-haystack) — «lost in the middle»:
  теряет ли LLM факты в середине длинного контекста. Пост: <https://t.me/technosurvival/54>

## Структура

```
experiments/<slug>/
  README.md    что это, как запустить, сколько стоит
  *.py         код эксперимента
  scripts/     вспомогательные скрипты (графики, подготовка данных)
  data/        данные (если не генерируются на лету)
  results/     результаты прогонов (в git не попадают)
```
