# ai-medicine — промпт персонального ИИ-медика

Материал из поста канала «Техновыживание»: как я собрал личного ИИ-консультанта
по здоровью на OpenCode + DeepSeek.
Пост: https://t.me/technosurvival/57

## Что это

`AGENT_PROMPT.md` — стартовый промпт для AI-агента (например, OpenCode), который
превращает его в «персонального медицинского куратора»:

- извлекает историю болезни из PDF (pymupdf, OCR для сканов);
- строит гибридный поиск по SQLite (FTS5 + эмбеддинги);
- ведёт профиль пациента, дневник и цели;
- вырезает персональные данные перед отправкой в LLM.

Промпт устроен так, чтобы агент **сначала задал вопросы и составил план** и только
после твоего подтверждения начал строить систему.

## Как использовать

1. Скопируй `AGENT_PROMPT.md` своему AI-агенту как стартовую инструкцию.
2. Ответь на вопросы агента (приватность, модель, интерфейс, источники).
3. Подтверди план — дальше агент сам строит пайплайн: PDF → SQLite → гибридный
   поиск → дневник.

## Важно

- Это **не замена врачу**: агент не ставит диагнозов и не отменяет назначения.
- Медицинские данные хранятся локально; во внешние LLM уходит только обезличенный текст.
