# llm-anonym — обезличивание договора перед нейросетью

Эксперимент из поста канала «Техновыживание»: что будет, если закупщик или юрист
засунет договор в нейросеть — и как он попытается спрятать реквизиты.
Пост: https://t.me/technosurvival/55

## Что делает инструмент

`anonymize.py` берёт твой PDF и выдаёт **два варианта** обезличенного документа:

1. **Вырезание** (`*_redacted.pdf`) — реквизиты закрыты чёрными полосами прямо в PDF.
2. **Сохранение формата** (`*_format_preserving.pdf`) — реквизиты заменены на
   синтетику с сохранённой структурой (ИНН выглядит как ИНН, телефон — как
   телефон).

Найденные сущности печатаются в консоль — можно проверить, что ничего не
пропустили.

## Какие инструменты есть и что мы используем

У Presidio (фреймворк обезличивания) есть несколько механизмов поиска сущностей:

- **spaCy NER** — нейросеть, обученная на размеченном тексте. Находит «мягкие»
  понятия — ФИО, организации, города, email. Бывает английская и русская модель.
- **регэкспы** — это правила, а не нейросеть. Идеальны для жёстких форматов —
  ИНН, БИК, счета, телефоны, индексы.
- **GLiNER** — zero-shot NER: ты сам называешь, какие типы искать, без дообучения.

**Что используем мы** — гибрид: русский spaCy (ФИО / организации / города / email)
+ кастомные регэкспы (ИНН, КПП, ОГРН, БИК, счета, индексы, телефоны). GLiNER и
английский spaCy пробовали — на русском проиграли: GLiNER путал ИНН с ОГРН,
английская модель выдавала мусор.

## Запуск

### Docker (рекомендуется — там всё уже стоит)

```bash
docker compose build llm-anonym
docker compose run --rm llm-anonym --input sample/dogovor.pdf --output out
```

Результаты появятся в `out/` на хосте (volume). Образ тяжёлый (~2–3 ГБ из-за
spaCy-моделей large) — собирается один раз.

### Локально

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_lg
python -m spacy download ru_core_news_lg
python anonymize.py --input sample/dogovor.pdf --output out
```

## Вручную — восстановление по крошкам (деанонимизация)

1. Возьми `*_redacted.pdf` или `*_format_preserving.pdf`.
2. Загрузи в ChatGPT (желательно с поиском и vision) или DeepSeek и спроси:
   «кто заказчик и через какие банки работают стороны? Проведи расследование по
   косвенным признакам — масштаб, коды городов, отрасль — используй поиск».
3. Модель восстановит компанию (и частично банки) по неявным признакам — даже
   если реквизиты вырезаны или синтетические.

Вывод: анонимизация защищает реквизиты, но не «профиль» — имя восстанавливается
по совокупности неявных признаков, а поиск это только усиливает.

## Sample-документ

`sample/dogovor.pdf` — демо-договор (название компании настоящее, реквизиты
вымышленные), чтобы попробовать инструмент без своего документа.

```

fonts/           DejaVu для перерендера PDF с кириллицей
sample/          демо-договор для проверки
out/             сюда падают результаты (в git не попадает)
```
