# genealogy — промпт агента для генеалогических исследований

Материал из поста канала «Техновыживание»: как я за месяц собрал семейное древо
из 47 человек с помощью ИИ-агента.
Пост: https://t.me/technosurvival/63

## Что это

`AGENT_PROMPT.md` — стартовый промпт для AI-агента (например, OpenCode), который
превращает его в помощника для генеалогии:

- принимает фотографии и документы (OCR, каталог с ID и подписями);
- строит проверяемое родословное древо из структурированного JSON;
- собирает PDF-альбом «Семейный альбом»;
- делает резервные копии (Яндекс.Диск, политика copy без удаления).

## Ключевые принципы (зашиты в промпт)

- **Сначала вопросы и план → потом установка.** Агент не строит ничего до подтверждения.
- **Не фантазировать:** нет источника → «неизвестно». Три уровня уверенности: документ / семейная память / гипотеза.
- **Древо рисует только код** (JSON → Graphviz), а не модель — нейросеть путает людей.
- **Оригиналы фото/документов не перезаписываются и не удаляются.**

## Как использовать

1. Скопируй `AGENT_PROMPT.md` своему AI-агенту как стартовую инструкцию.
2. Ответь на вопросы агента (три блока интервью).
3. Подтверди план — агент сам строит пайплайн: документы → SQLite → древо → альбом → бэкап.

## Важно

- Секреты (токены, куки) — в отдельном каталоге `secure`, права 600, никогда в git.
- Промпт сгенерирован самим агентом в ходе работы над проектом.
