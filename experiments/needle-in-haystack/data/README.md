# Data

## texts/

Стога сена («haystack») — три книги из Project Gutenberg (public domain), у
которых убрана служебная шапка, строки свёрнуты в абзацы, а текст обрезан на
границе абзаца до ~100K токенов токенизатора DeepSeek V3.2.

В эксперименте книги склеиваются и обрезаются до нужного размера
(`--target-chars`, по умолчанию 500000 символов ≈ 115K токенов).

Файлы уже в репозитории — для запуска эксперимента ничего скачивать не нужно.

Пересобрать (опционально): `python scripts/prepare_texts.py [--target-tokens 100000]`
(потребует `tokenizers`, `huggingface_hub`, `requests`).

Иголки (числовые маркеры) генерируются скриптом на лету детерминированно
(seed) — их хранить не нужно.
